# Local visual assets

## Brand
- `brand/clavis-logo.png` — transparent, print-ready version of the exact Clavis logo supplied for this project.
- `brand/clavis-logo-source.png` — untouched source image, retained for reference.

## Icons
- `icons/doctor.svg`, `icons/clinic.svg`, `icons/diagnosis.svg`, `icons/lab.svg`, `icons/medication.svg`, `icons/diet.svg`, `icons/lifestyle.svg`, `icons/next-steps.svg`, `icons/calendar.svg`, `icons/notes.svg`, `icons/summary.svg`, `icons/summary-white.svg`, `icons/important.svg`.
- `lifestyle.svg` and `next-steps.svg` are separate vector assets used in the Lifestyle & Next Steps panel.

## Fonts
- `fonts/Inter-*.otf` — bundled Inter font weights used by the print stylesheet.

All visual assets are local. The template references each file by path; no external network requests are needed at render time.
